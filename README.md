
## User Stories for the “Patient Care” Context

# User Story 1: Book an Appointment

As a patient,
I want to book a medical appointment online,
so that I can schedule a consultation without visiting the hospital physically.

```gherkin
1. The patient should be able to select a doctor.
2. The patient should be able to select an available date and time.
3. The system should confirm the appointment after successful booking.
4. The system should prevent the patient from booking an already occupied time slot.
5. The appointment should be saved in the Patient Care system.
```

## User Story 2: View Patient Medical Information

As a doctor,
I want to view a patient’s medical information,
so that I can make informed decisions when providing treatment.


```gherkin
1. The doctor should be able to search for a patient.
2. The system should display the patient’s basic information.
3. The system should display relevant medical history.
4. Only authorized healthcare staff should be able to access the information.
5. The system should display the information accurately and securely.
```
